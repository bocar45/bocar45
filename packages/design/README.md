# @sawwa/design
Le document de création SAWWA (`DesignDocument`, millimètres réels, origine = coin haut-gauche de la zone, x/y = centre du calque), sa validation (`parseDesign`), la géométrie (boîtes avec rotation, surface imprimée, dpi effectif), le contrôle de fabrication par technique (`preflight`) et le passage vers le moteur de prix (`decorationsFor`). Pur, sans dépendance.
